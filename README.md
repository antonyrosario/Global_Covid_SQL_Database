# COVID-19 Vaccination Data Analysis with SQL

## 📌 Project Overview

This project analyzes COVID-19 vaccination trends globally using SQL.

## 🔍 Skills Demonstrated

- Database Design & Normalization (3NF)
- SQL Queries for Data Analysis
- Data Cleaning & Transformation
- Data Visualization with SQL

## 📂 Project Structure

```
SQL-Portfolio-Project/
│── README.md
│── sql/
│   ├── Database.sql  (SQL script to create tables)
│   ├── Queries.sql  (SQL queries used for analysis)
│── docs/
│   ├── Model.pdf (ER Diagram and Normalization)
│── .gitignore
```

## 📊 Data Source

The dataset used is inspired by the **Our World in Data COVID-19 Vaccination Dataset**. You can access similar public data here:

- [**Our World in Data - COVID-19 Vaccination Dataset**](https://github.com/owid/covid-19-data/tree/master/public/data/vaccinations)



## 💪 Technologies Used

- **SQLite Studio** for database design
- **SQL** for querying and analysis
- **Excel / Tableau** for visualization
